# Celebrate With Creativity — Festival Promotion Landing Page

Responsive React + Tailwind CSS landing page for the festive promotion.

## Included
- Exact uploaded promotion poster at `public/festival-promo.jpg`
- Cream, maroon, forest green and gold design
- Hero section, package cards, festival list, 3-step ordering guide and CTA
- WhatsApp order links with pre-filled messages
- Mobile floating WhatsApp button
- Responsive desktop and mobile layouts
- GitHub Actions workflow for automatic GitHub Pages deployment

## Run locally
1. Install Node.js (LTS).
2. Open a terminal in this folder and run:

   ```bash
   npm install
   npm run dev
   ```

3. Open the local URL printed by Vite.

## Host on GitHub Pages
1. Create a new GitHub repository.
2. Upload/push all files and folders in this project to the repository's `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **GitHub Actions** as the source.
5. Open the **Actions** tab and wait for **Deploy to GitHub Pages** to finish.
6. Your site URL will be shown in the deployment job and under **Settings → Pages**.

Every push to `main` will trigger a new deployment automatically.
